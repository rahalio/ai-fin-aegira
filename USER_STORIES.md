# Aegira — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### Head of fraud

- As a head of fraud, I want champion/challenger lift reported weekly, so that we promote models on evidence.
- As a head of fraud, I want false-positive cost beside loss prevented, so that we stop “winning” by blocking good customers.

### Fraud investigator

- As an investigator, I want a prioritised case queue with reason codes and feature highlights, so that I do not reverse-engineer scores.
- As an investigator, I want one-click dispositions that feed model feedback, so that my work improves tomorrow’s queue.
- As an investigator, I want to link related cases by device or payee, so that I catch organised patterns.

### Model owner

- As a model owner, I want shadow-mode metrics before promotion, so that we do not surprise the authorisation path.
- As a model owner, I want instant rollback if precision collapses, so that incidents are minutes not change weekends.

### Queue manager

- As a queue manager, I want SLA breach heatmaps by segment, so that I staff peaks.
- As a queue manager, I want auto-priority for high-value or vulnerable-customer segments per policy.

### Customer care lead

- As a care lead, I want safe case status for inbound callers, so that agents can unblock legitimate customers quickly.

### Platform administrator

- As an administrator, I want strict tenant and PCI data controls, so that investigations do not become a data lake free-for-all.
- As an administrator, I want audit logs for every model promotion and case access, so that we pass assurance reviews.
